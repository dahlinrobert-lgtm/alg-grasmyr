# Rådata

Lägg originalfiler direkt från statistikportalen här, sorterade per statistiktyp, exempelvis:

```
data/raw/
  avskjutning/
  algobs/
  slaktvikter/
  biologiska_data/
```

Byt inte namn på eller redigera själva innehållet i originalfiler i efterhand. Filnamnet bör ange områdesidentitet och jaktårsintervall. Spara valda filter och tidpunkt i en notering eller separat metadatafil. Lägg inte in filer som innehåller personuppgifter.
